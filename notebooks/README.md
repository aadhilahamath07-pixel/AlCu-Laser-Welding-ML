# Research notebooks

Run notebooks in numerical order. The notebooks are designed for Google Colab and use repository source files or generated CSV outputs.

| Notebook | Stage | Main output |
|---|---|---|
| 01 | Original-file inspection | Workbook/text inspection and source inventory |
| 02 | Conventional data cleaning | Standardised conventional records |
| 03 | Conventional dataset build | `conventional_laser_welding_standardized.csv` |
| 04 | Wobble dataset build | `alcu_wobbling_welding_standardized.csv` |
| 05 | Master construction | `master_experimental_dataset.csv` and audit/data dictionary files |
| 06 | Master quality control | `master_experimental_dataset_qc.csv`, QC reports and target-specific subsets |
| 07 | Exploratory data analysis | Source-specific EDA, eligibility-aware correlations, target value/concentration audit, repeat summaries, `wobbling_ml_dataset.csv` and ZIP export |
| 08 | Wobble grouped ML evaluation | Fold-wise metrics, pooled out-of-fold metrics, out-of-fold predictions, diagnostic plots and ZIP export |
| 09 | Conventional grouped ML evaluation | Leave-one-condition-out metrics for bead width, interface width and penetration depth; pooled predictions and ZIP export |

## Execution notes

- Sign in to the intended Google account before opening Colab.
- Notebook outputs are not automatically committed to GitHub.
- Notebook 06 expects the master CSV produced by Notebook 05.
- Notebook 07 expects the audited `master_experimental_dataset_qc.csv` produced by Notebook 06. It applies target-specific eligibility to summaries, plots and correlations, audits concentrated values, and creates `wobbling_ml_dataset.csv` from records eligible for both wobble bead-width targets. The CSV is also included in the Notebook 07 output ZIP and is the input to Notebook 08.
- Notebook 08 expects `wobbling_ml_dataset.csv` generated by Notebook 07. It uses five-fold GroupKFold validation by process condition and exports fold metrics, pooled out-of-fold metrics, predictions and diagnostic plots in Colab. Upload the CSV when prompted.
- Notebook 09 expects `conventional_laser_welding_standardized.csv` from Notebook 03. It evaluates the three conventional geometry targets separately using leave-one-process-condition-out validation. It excludes the six all-zero geometry records from this default regression experiment while preserving them in the source/master datasets. Upload the CSV when prompted.
- Keep downloaded outputs with their source and notebook version; do not overwrite raw data.
